El bucle for dentro de un for: dos contadores, dos carros y nueve combinaciones

CONTROL_DUAL_ANIDADO
let filas = ['A', 'B', 'C']; let columnas = [1, 2, 3]; for (let i = 0;      i < filas.length; // externo      i++) { // externo    for (let j = 0; // se reinicia        j < columnas.length;        j++) {         console.log(filas[i] + columnas[j]);    } }
TERMINAL // STDOUT
NOTAS_DE_OPERADOR
· El interno se reinicia solo: al agotarse, j vuelve a 0. · i solo avanza cuando j ya recorrió la fila completa. · 3 vueltas externas × 3 internas = 9 cuerpos ejecutados.
Arquitectura del Bucle Anidado
3 FILAS × 3 COLUMNAS ➔ 9 COMBINACIONES
